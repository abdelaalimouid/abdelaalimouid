#### Featured: [qgis-agent](https://github.com/abdelaalimouid/qgis-agent)

An open-source skill that makes AI agents work in QGIS like careful analysts: a plan before acting, QGIS's own tools, and every result checked before it is handed over. Tested on Linux, macOS and Windows, with QGIS 3 and 4. [Website and gallery](https://abdelaalimouid.github.io/qgis-agent/)
